# Frontend Lab

An independent collection of frontend projects created for learning, practice, and portfolio demonstrations.
Some pages are UI recreations and are clearly labeled as independent, fictional previews. They are not affiliated
with or endorsed by the brands they may reference. The demonstrations do not collect credentials or sensitive
personal information.

Open [the project gallery](./index.html) to explore the available demos.
